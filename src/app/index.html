Google Authenticator secret retriever

Drop in a screenshot of the Export accounts code. This page decodes the QR, reads the payload inside it, and lists every account with its base32 secret and the parameters that go with it.

Everything happens in this page. There is no code here that opens a network connection, so nothing you load can be sent anywhere. Turn your connection off and use it anyway: that is the check worth doing, and it works.

Add an export code

Drop a screenshot anywhere on this page, paste one, choose a file, or use the camera. Google Authenticator splits large exports across two or three codes; add them one at a time in any order.

The camera is not available here, which is usual when this file is opened directly from disk. Dropping or pasting a screenshot always works. To use the camera, serve this file over http: run python3 -m http.server in the folder holding it and open the address it prints.

Accounts

Treat the export code as you would the passwords themselves

A Google Authenticator export code carries the secret key for every account inside it. Anyone who photographs it, or finds the screenshot in a photo backup a year from now, can generate your codes indefinitely. Changing your password does not revoke it. Removing the app does not revoke it.

So do this on a device you trust, on a screen nobody is standing behind. Do not send the code to yourself in a chat to have it handy, and delete the screenshot when you are finished, including from the recently deleted folder.

The secrets shown above are as sensitive as the code they came from. They are held in this page and nowhere else, so closing the tab is enough. Copying one out makes it your job to look after.
